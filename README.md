# 充填溫度日報

五惠食品 品保課使用的「PE袋充填機 進料端溫度紀錄」日報工具。

上傳記錄器匯出、並已標註好的 Excel 檔，系統會：

1. 檢查標註是否完整（缺漏時指出第幾列，請現場修正後重新上傳）
2. 依品項畫出充填段的連續溫度曲線與單趟放大圖，低於標準的數值以紅色標示
3. 一鍵產生 **A4 直式 PDF 日報**（檔名：`YYYY-MM-DD PE袋充填溫度日報.pdf`，日期在前方便依日期排序）

網址：<https://jackielin666.github.io/filling-temp-report/>

## 登入

- 輸入公司給你的帳號和密碼即可（不用打信箱）。
- 系統會記住這台電腦**上一次登入的帳號**，下次只要輸入密碼（不會記住密碼）。換人使用時，直接把帳號欄改掉即可。
- **閒置 15 分鐘會自動登出**，登出前 1 分鐘會提醒；動一下滑鼠或按任意鍵即可繼續。
- 忘記密碼或需要新帳號，請聯絡系統管理者 Jackie。

## 上傳前，Excel 要標註 2 件事

標準值固定為 **≥80°C**，D2 和標題列（基準值、品項）都不用填。支援 .xlsx、CSV、Tab 分隔文字檔，副檔名寫錯也沒關係。

| # | 位置 | 填什麼 |
|---|---|---|
| 1 | **D 欄**（第 3 列以下） | 每一趟的開始、結束標記：`開始／結束`、`S／E`、`START／END`（大小寫不拘） |
| 2 | **E 欄** | 品項，只填在該品項**第一趟的開始列**；換品項時再填 |

## 會被擋下來、要求重新上傳的情況

- 整份檔案沒有任何開始／結束標註
- 開始、結束沒有成對
- 第一趟沒有填品項
- D 欄出現無法辨識的文字或數字

> 記錄器漏記、時間中斷等**資料缺失不會擋下**，報告圖上會用灰色斜線標示「資料缺失」。

## 資料安全

- 溫度資料只在使用者自己的瀏覽器處理，**不會上傳到任何伺服器**。
- 本 Repo 只放網頁程式，不放任何溫度資料、帳號或密碼。
